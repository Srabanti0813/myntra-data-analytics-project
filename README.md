# Myntra Excel Sales Dashboard

An Excel data analytics project that cleans, analyzes, and visualizes Myntra product data to uncover insights on brands, prices, discounts, ratings, customer engagement, and estimated revenue.

## Project Overview

This project analyzes Myntra product data using Microsoft Excel. It transforms raw data into a cleaned dataset, calculates important business metrics, creates pivot-table summaries, and presents insights through an interactive brand dashboard.

## Tools Used

- Microsoft Excel
- Excel Formulas
- Pivot Tables
- Charts and Dashboard Visualizations

## Data Cleaning

- Removed unnecessary columns and retained relevant product details
- Cleaned product, brand, rating, price, and category data
- Created a refined dataset for analysis
- Compared uncleaned and cleaned data records

## Key Metrics Created

- Product count
- Unique brand count
- Average product rating
- Maximum and minimum marked price
- Maximum and minimum discounted price
- Estimated revenue
- Total customer engagement using rating count
- Discount percentage
- Discount classification: `Good Discount` or `Negligible`

## Analysis Performed

- Brand-wise product and rating-count analysis
- Average discounted price and marked price by brand
- Estimated revenue by brand
- Product-category count by brand
- Product price and discount comparison
- Rating and customer-engagement analysis

## Dashboard Visualizations

The dashboard includes:

- Brand performance charts
- Revenue analysis
- Rating-count analysis
- Price comparison
- Product-category distribution
